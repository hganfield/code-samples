## Final Project

filename: Final_Project_Final_Version.ipynb

The purpose of this project is to determine what personal and network characteristics of police officers best predict the rate of complaints against them over the extent of an officer's career. Following up on my project from Social Network Analysis, I created a bipartite network of officers and complaint reports using data obtained from the Invisible Institute. I calculated network characteristics, such as centrality, to use as factors along with personal characteristics, like gender, age, and rank. Using a variety of supervised learning models, I found the strongest predictor for a high rate of complaints was betweenness centrality, which means an officer acts as a "broker" in the network by connecting other officers to one another.
