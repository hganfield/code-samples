# Code Samples

This repository contains coding projects from my master's degree in social science at the University of Chicago. 

## MACS 33002: Introduction to Machine Learning

This course was offered through the computational social science department. This course introduced machine learning techniques in Python using the scikit-learn package, covering the full machine learning pipeline: data preparation; supervised and unsupervised learning; and model evaluation, validation, and interpretation. The course emphasized social science applications such as analyzing social behavior and public opinion, predicting market trends, and informing public health and policy decisions.

Final grade: A

## MACS 40101: Social Network Analysis

This course was offered through the computational social science department. This ccourse covered theoretical concepts and applied techniques for understanding networks from a social sciences perspective. Topics included: fundamental concepts and theories, research design and data collection; whole and ego networks; centrality; cohesive subgroups and network communities; equivalence and blockmodeling; affiliation networks; and statistical models. This course was conducted in R.

Final grade: A

## PLSC 30600: Causal Inference

This is the second course in quantitative methods in the Political Science PhD program. The course is an introduction to the theory and practice of causal inference from quantitative data. Topics included: potential outcomes framework, the design and analysis of experiments, matching, weighting, regression adjustment, differences-in-differences, instrumental variables, regression discontinuity designs, and two way fixed effects. This course was conducted in R.

Final grade: A
