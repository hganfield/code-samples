# PLSC 30700: Causal Inference

This folder contains two coding samples from the coursework. Both are take-home coding exams. 

## Midterm
In this file, I used non-experimental data as observational controls for an experimental group in order to calculate the average treatment effect of the treated using a variety of estimators: difference-in-difference, lin regression adjustment, IPW, and the doubly-robust estimator. 

## Final
This assignment was a difference-in-difference exercise using panel data. I estimated a two-way fixed effects model, interpreted an event study plot, and used Sun-Abraham's estimator to estimate effects allowing for staggered adoption.
